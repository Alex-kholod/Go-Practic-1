### Установка и запуск
1. Клонирование репозитория (только ветка текущей практики)
```bash
git clone -b pz8 --single-branch https://github.com/Alex-kholod/Go-Practic-1.git
```
2. Переход в директорию проекта
```bash
cd Go-Practic-1
```
4. Запуск MongoDB
```bash
docker compose up -d
```
4. Запуск приложения
```bash
go run ./cmd/api
```
