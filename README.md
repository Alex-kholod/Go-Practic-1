### Установка и запуск
1. Клонирование репозитория (только ветка текущей практики)
```bash
git clone -b pz9 --single-branch https://github.com/Alex-kholod/Go-Practic-1.git
```
2. Переход в директорию проекта
```bash
cd Go-Practic-1
```
3. Запуск приложения
```bash
cd .\app\
go run ./cmd/api
```
